Waypoints is designed to keep itself up-to-date automatically[^1]. You can, always change this behavior in your settings though!

## Automatic Updates

By default, Waypoints checks for updates and installs them automatically the next time you restart the app. You'll always be running the latest version with no extra steps.

If an update is available, Waypoints will download it in the background and apply it on restart.

## Checking your current version

To check which version of Waypoints you're using:

1. Open the Command Palette (:kbd{value="meta"} :kbd{value="shift"} :kbd{value="P"})
2. Type and select `waypoints: about`.

You should see a modal that has your version information.

## Controlling the update behavior

If you want to turn off auto-updates, open the Settings Editor (:kbd{value="meta"} :kbd{value=","}) and find "Auto Update" under General Settings.

---

[^1]: We disable this on some platforms, like NixOS, to adhere with the idempotent builds. Generally speaking, though, if you don't know what this means, **assume Waypoints will auto-update**.
