  **Bug this surfaced**: `build.rs` reads the channel from `WAYPOINTS_FLAVOR` (as `src-tauri/justfile` exports), which the derivation never set — so every Nix package reported `channel = "development"` regardless of flavor, while its product name, identifier, icons and update endpoint were all correct.
